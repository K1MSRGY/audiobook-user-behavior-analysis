# audiobook-user-behavior-analysis
PostgreSQL project for analyzing user behavior in an audiobook service

## Описание проекта

SQL-проект по анализу поведения пользователей сервиса аудиокниг.

## Инструменты

- PostgreSQL
- SQL

## Задачи проекта

- Определить количество пользователей, добавивших книгу
- Проанализировать глубину прослушивания
- Рассчитать количество уникальных слушателей
- Определить наиболее популярные аудиокниги
- Проанализировать завершенные прослушивания
- Исследовать активность пользователей по операционным системам

## Использованные SQL-инструменты

- JOIN
- GROUP BY
- COUNT DISTINCT
- Подзапросы
- Агрегатные функции
- Фильтрация данных

## Результат

Проект демонстрирует использование SQL для анализа пользовательского поведения и работы с несколькими связанными таблицами.
